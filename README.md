# Exploratory Data Analysis of Student Grades

**Author:** Makayla McKenzie  
**Tools:** R, R Markdown  
**Date:** October 2025  

## Project Overview
This project demonstrates an exploratory data analysis (EDA) on student grade data. It includes data cleaning, statistical analysis, and visualizations to identify trends and insights.  

## Files Included
- `Project1.Rmd` – R Markdown file with all code and analysis.  
- `Project1.pdf` – Rendered PDF report of the analysis.  

## Key Skills Demonstrated
- Data manipulation and cleaning in R  
- Data visualization and interpretation  
- Reporting results in R Markdown  
- Reproducible research practices  

## How to View
- The PDF can be viewed directly in GitHub.  
- The R Markdown file can be opened and run in RStudio for full analysis.
